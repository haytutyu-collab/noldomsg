# Noldo — как запустить и поделиться с друзьями

Это пошаговое руководство объясняет, **как запустить Noldo** прямо сейчас (без установки чего-либо) и **как выложить его в интернет**, чтобы родные и друзья могли заходить со своих телефонов.

---

## Часть 1. Попробовать прямо сейчас (без установки)

У вас уже есть готовый Noldo, работающий по ссылке-превью. Чтобы друзья могли заходить:

1. **Скопируйте ссылку-превью** из чата (это ссылка вида `https://preview-xxxx.space-z.ai/`).
2. **Отправьте её родным** в любой мессенджер — Telegram, WhatsApp, SMS, email.
3. Родные открывают ссылку в **Safari (iPhone)** или **Chrome (Android)**.
4. На экране входа нажимают **«Регистрация»**, вводят имя (например, «Папа») и пароль (минимум 4 символа).
5. Готово — вы увидите друг друга в списке «Чаты» автоматически.

### Установить как приложение на телефон

Чтобы Noldo открывался как обычное приложение с иконкой на главном экране:

**iPhone (Safari):**
1. Откройте ссылку в Safari
2. Нажмите кнопку «Поделиться» (квадрат со стрелочкой вверх) внизу
3. Прокрутите вниз → «На экран „Домой“»
4. Нажмите «Добавить» — иконка Noldo появится на главном экране

**Android (Chrome):**
1. Откройте ссылку в Chrome
2. Нажмите меню (три точки в правом верхнем углу)
3. «Установить приложение» / «Добавить на главный экран»
4. Подтвердите — иконка появится на рабочем столе

После установки Noldo открывается в полноэкранном режиме без адресной строки — выглядит как обычное приложение.

## Часть 2. Выложить в интернет «по-настоящему» (бесплатно)

Превью-ссылка живёт, пока активна эта сессия разработки. Если вы хотите, чтобы Noldo работал **всегда** (24/7, даже когда вы не в браузере), его нужно задеплоить на хостинг. Вот бесплатный способ — **3 шага**:

### Что понадобится

- Аккаунт на **GitHub** (бесплатно)
- Аккаунт на **Vercel** (https://vercel.com — бесплатно, вход через GitHub)
- Аккаунт на **Render** или **Railway** (для WebSocket-сервиса — бесплатно)
- Аккаунт на **Neon** или **Supabase** (для базы данных PostgreSQL — бесплатно)

### Шаг 1. Подготовить код

Скачайте весь проект в zip-архив из этого чата (или сделайте `git clone`, если есть репозиторий). Затем создайте новый репозиторий на GitHub и запушьте туда код:

```bash
cd my-project
git init
git add .
git commit -m "Noldo messenger"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/noldo.git
git push -u origin main
```

### Шаг 2. Настроить базу данных (Neon PostgreSQL)

1. Зайдите на https://neon.tech, создайте бесплатный проект
2. Скопируйте connection string вида `postgresql://user:pass@host/db?sslmode=require`
3. В файле `prisma/schema.prisma` замените провайдер:
   ```prisma
   datasource db {
     provider = "postgresql"   // было "sqlite"
     url      = env("DATABASE_URL")
   }
   ```
4. Локально выполните `bun install && bunx prisma db push` с `DATABASE_URL` из Neon, чтобы создать таблицы

### Шаг 3. Задеплоить фронтенд на Vercel

1. Зайдите на https://vercel.com, нажмите «New Project»
2. Импортируйте ваш GitHub-репозиторий
3. **Framework preset:** Next.js
4. **Environment Variables** (обязательно):
   - `DATABASE_URL` = ваш Neon connection string
   - `VAPID_PUBLIC_KEY` = из вашего `.env`
   - `VAPID_PRIVATE_KEY` = из вашего `.env`
   - `VAPID_SUBJECT` = `mailto:ваш@email.com`
   - `NEXT_PUBLIC_APP_URL` = `https://noldo.vercel.app` (ваш будущий домен Vercel)
5. Нажмите **Deploy** — через минуту получите ссылку вида `https://noldo-xxx.vercel.app`
6. Укажите её друзьям — это и есть **ваш постоянный адрес мессенджера**

### Шаг 4. Задеплоить WebSocket-сервис на Render

Сервис реал-тайма (звонки, набор текста, наличие в сети) живёт отдельно.

1. Зайдите на https://render.com, создайте новый **Web Service**
2. Подключите тот же GitHub-репозиторий
3. **Root Directory:** `mini-services/chat-service`
4. **Build Command:** `bun install`
5. **Start Command:** `bun index.ts`
6. План: **Free**
7. Deploy — получите URL вида `https://noldo-chat.onrender.com`

### Шаг 5. Соединить фронтенд и WebSocket-сервис

В файле `src/app/page.tsx` найдите строку:
```ts
const socket = io('/?XTransformPort=3003', {
```
И замените на:
```ts
const socket = io('https://noldo-chat.onrender.com', {
  transports: ['websocket', 'polling'],
  // ... остальное оставьте
})
```

Также в `next.config.ts` добавьте домен Render в `images.remotePatterns`, если будете использовать аватарки.

Закommittите и запушьте — Vercel автоматически пересоберёт сайт. Готово! 🎉

## Часть 3. Что важно знать про звонки

**Звонки (аудио и видео)** работают через **WebRTC**. Это технология прямого соединения между двумя браузерами — звук и видео идут напрямую от телефона к телефону, не через сервер.

### Когда звонки работают сразу

- Оба телефона в **домашней Wi-Fi сети**
- Один из телефонов в обычной домашней сети (без строгого NAT)
- Звонящий и принимающий на разных сетях, но без агрессивных фаерволов

### Когда звонки могут не работать без TURN-сервера

Если оба телефона сидят за **carrier-grade NAT** (мобильный интернет у обоих), за корпоративным фаерволом или в очень строгой сети — прямое соединение не устанавливается. Нужен **TURN-сервер** (релай).

**Бесплатный вариант (для начала):**
В файле `src/components/messenger/call-screen.tsx` уже прописаны бесплатные STUN-серверы Google:
```ts
const ICE_SERVERS = [
  { urls: 'stun:stun.l.google.com:19302' },
  { urls: 'stun:stun1.l.google.com:19302' },
]
```

**Если звонки не проходят:** добавьте свой TURN-сервер. Бесплатный — `openrelay.metered.ca:80` (см. https://www.metered.ca/stun-turn). Платный надёжный — Twilio STUN/TURN (~$0.0004 за минуту). Добавьте его так:
```ts
const ICE_SERVERS = [
  { urls: 'stun:stun.l.google.com:19302' },
  {
    urls: 'turn:ваш-turn-сервер:3478',
    username: 'ваш-юзер',
    credential: 'ваш-пароль',
  },
]
```

## Часть 4. Что важно знать про push-уведомления

Push-уведомления работают **только на HTTPS** (Vercel даёт HTTPS бесплатно — ок).

На **iPhone** push-уведомления от PWA-приложений появились только в **iOS 16.4+**. Убедитесь, что у родных свежий iOS. На Android всё работает без проблем.

Чтобы push пришёл:
1. Пользователь должен **один раз** включить уведомления в «Профиле» → «Включить»
2. Браузер спросит разрешение — пользователь должен согласиться
3. После этого когда кто-то отправляет сообщение, получателю (если он не в активной вкладке Noldo) придёт системное уведомление с именем отправителя и текстом сообщения

Если приложение **установлено на главный экран** как PWA — уведомления работают как у обычного приложения: иконка, вибрация, баннер на экране блокировки.

## Часть 5. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Не вижу собеседника в списке чатов | Он зарегистрировался под другим именем? Оба на одной ссылке? |
| Сообщения не приходят real-time | Проверьте, что оба онлайн (зелёная точка). Перезагрузите страницу. |
| Звонок не соединяется | Скорее всего строгий NAT. Добавьте TURN-сервер (см. Часть 3). |
| Push не приходят | iPhone: проверьте версию iOS (нужна 16.4+). Включены ли уведомления в профиле? |
| Аватарка не загружается | Файл больше 10 МБ? Используйте фото поменьше. |
| На iPhone не устанавливается как приложение | Открывайте в **Safari**, не в Chrome. Только Safari умеет ставить PWA на iPhone. |
